# Portal Mahasiswa

Aplikasi web sederhana untuk pengelolaan data mahasiswa yang dibangun menggunakan Vite, TypeScript, dan Git.

## Fitur Utama

- Definisi tipe data mahasiswa berbasis `Interface` dan `Union Type`.
- Implementasi fungsi `Generic` untuk manipulasi data array.
- Konfigurasi environment variables melalui `.env`.

## Prasyarat

- Node.js
- npm

## Cara Menjalankan Proyek Lokal

1. **Clone Repository**
   ```bash
   git clone [https://github.com/pikaxell/portal-mahasiswa.git]
   cd portal-mahasiswa
   ```
